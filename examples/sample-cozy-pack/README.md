# Sample Cozy pack

Four cozy living-room pictures (morning, day, evening, night), 1280 x 720, no people.
They were made for this project with an AI image generator and are released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/): use them however you like.

No music is included. Add your own `music.mp3` (or `.ogg` / `.m4a`) to this folder before pushing it,
or leave it out and the home screen stays quiet.

Try it:

```bash
scripts/push-cozy-pack.sh 192.168.1.50 examples/sample-cozy-pack --cozy
```

For a sharper picture on a 4K TV, use your own 1920 x 1080 or 3840 x 2160 images.
