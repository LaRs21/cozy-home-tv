# Starting list for Google TV / Android TV (used when no brand list matches the TV).
# ./setup.sh offers it as tiers; scripts/debloat.sh can try it by hand.
#
# Format:  <tier> <package> [bg]   # what it is / what you lose
#   safe  optional apps you can turn off without side effects
#   more  safe, plus apps most people don't need (read the note)
#   ask   asked one by one, never turned off without a yes (skipped with --yes)
#   bg    don't turn the app off; only stop it running in the background
# Apps are only turned off (pm disable-user --user 0), never uninstalled; ./restore.sh turns them back on.
# The protect list in scripts/lib.sh (launchers, setup, Play services/Store, keyboards, Live TV / tuner / HDMI,
# OTA, network, System UI, chip-vendor system apps) is enforced whatever this file says.

# --- Optional Google apps ---
safe com.google.android.youtube.tvmusic     # YouTube Music (the YouTube app keeps working)
safe com.google.android.play.games          # Google Play Games

# --- Screensavers (only if you use Cozy Home TV's screensaver) ---
more com.android.dreams.basic               # the basic "Colors" screensaver
# com.google.android.apps.tv.dreamx         # Google TV ambient photo screensaver: left on, Google TV settings use it

# --- Casting ---
ask  com.google.android.apps.mediashell     # Chromecast built-in: phones can no longer cast to the TV; frees ~20-40 MB RAM

# --- Not offered: they break things on some Google TV builds ---
# com.google.android.katniss                # Google Assistant / voice search: the mic button stops working
# com.google.android.videos                 # Google TV "Shop"/movies: on some builds the stock UI depends on it
